# ADR 0063 · 迁移到 MyGo 原生 UI

日期：2026-11-08  
状态：已采纳（原生路径）；旧 Tauri 实现转为 legacy

## 背景

项目的原始实现是 Tauri 2 + React 19 + TypeScript，已经验证了产品形态和
文件安全规则。用户在 2026-11-08 明确要求迁移到 MyGo 原生 UI、自研编辑
内核，并保持纯本地、低内存和低 CPU。新路线旨在直接控制文本存储、排版
与可见绘制的工作范围。当前没有同设备同负载的 Tauri/原生对照实验，
迁移动机不作为原生实现已经占用更少内存或启动更快的证明。

## 决策

采用 Go + MyGo v0.8.3 的原生 Surface 路径，`cmd/levnote` 使用
`Content: ui.View(...)` 创建界面。窗口和编辑区不在浏览器页面中运行。
MyGo 提供窗口、绘制、字体排版、原生输入传输和平台服务；不采用它现成的
Markdown、代码或富文本编辑引擎。文档生命周期、格式解析、查找、插件
管理和外壳由 LevNote 实现，模块边界见
[`native/ARCHITECTURE.md`](../../native/ARCHITECTURE.md)。

格式引擎保持纯 Go：不能直接访问文件，不能执行脚本，不能联网；主机 API
拥有文件读写与平台激活。未知字段与原始字节必须往返保留。降级、冲突、
预算耗尽和丢弃内容必须显式可见。

资源预算是一等约束，而不是事后优化。Markdown 解析保留完整 raw 源码，但
用确定性的 line/block/item/span/scan 上限截断解释，并用 `Partial` 和
警告拒绝不完整导出。磁盘后台检查使用不可变 token，不得访问可变
`Document`/`Buffer`。保存前的完整冲突检查仍由文档层权威执行。

大纲是可选的有界文档能力：源码模式通过轻量 `OutlineSource` 提取，不为
查看目录创建图形布局。Markdown 当前链接 slug 与跨版本范围身份分开，
导航先 Flush 再重解；导图展开折叠祖先属于文档编辑，须可撤销并遵守只读。
Markdown/导图之外，schema2 安装配置可用受限字面行规则提供源码大纲。
它通过独立 source factory 接入，不假装有富视图；配置不能执行代码，
不把声明式高亮/大纲规则描述成任意渲染插件 SDK。

原生任务方框保持同一源码权威：有限列表语法只增加元数据，交互在 Flush
后重解范围和语法上下文，再以单字符事务切换。原生控件身份与文档身份
分开，不使用标签文字或列表序号修复过期目标；HTML 导出方框不可交互。

原生行内链接遵守同样的来源身份和 Flush 边界，外部动作只交给宿主的
本地引用策略。普通选择/编辑不被链接控件抢占；密集段落依据实测绘制
开销限制交互数量，完整源码保留并给出可见提示，不静默截断地址。

Markdown doc-block 只把显式 `mode: reference` 且非空、最多4096字节的
`src` 暴露为导航按钮。解析器的结构诊断不承诺目标存在或宿主允许打开；
普通 inline 即使结构有效也不借 `src` 导航。按钮捕获 Buffer/版本、预览行、
整块与属性区的源码范围以及完整目标，先 Flush，再按范围日志重解并核对
同 Buffer、精确范围、doc-block 模式和目标。相同 ID/标题不会成为回退身份。
`OpenReference` 是唯一分类/打开出口且只调用一次，只读可导航，外部 URL、
UNC 和远程 file URL 仍由本地宿主策略拒绝。

Markdown 表采用独立实现的有限矩形管道表子集，不引入浏览器表格内核。
解析结果保存原始 UTF-8 单元格/物理行范围，宽布局用原生网格，窄布局把每个
物理行转为带列名的堆叠字面记录；表头+分隔+零正文行是有效状态。第一切片
提供整张表的现有源码草稿编辑，不提供结构工具条、公式、嵌套表或完整 GFM
承诺。后续第二切片把表头/正文单元格作为可聚焦目标，复用唯一的独立编辑器，
但输入只保留为视图本地草稿，不在每次按键时改宿主Buffer；Finish、保存或
切换前按当前完整解析重验并最多写回一次。无效值保留草稿与恢复入口，未写回
的值不被自动会话/崩溃快照捕获。反引号不保护未转义管道；无效或预算失败
候选保留完整 `Raw` 并显示一次有界回退，而不是构造看似完整的一部分表格。

表预算为8列、256正文行、每单元格4096 UTF-8字节、32 KiB完整表和每文档
16,384个cell描述项。完整 `Raw` 有意作为源码权威保留，超过32 KiB时预览
不物化整表布局。整表编辑手势在 Flush 后按 Buffer/版本/精确范围重验，
失败保留草稿，只读导航不创建编辑历史。安全 HTML 导出只输出转义后的字面
单元格，不激活其中的 Markdown/HTML/链接/图片。

导图主题、备注、链接共用一个原生字段编辑器。可选字段的缺失与显式空值
分别记录，写回按节点/字段/原存在性与值核对，只合并捕获字段。导航按钮
保留按下时的来源身份；待同步链接使用显式写回动作，成功后只打开核对过
的目标。文字保真与JSON排版保真分开：真实字段修改可重新序列化，未知
成员保留；不以只读/浏览动作制造写入。

MyGo 通过标准 Go vendor 模式固定版本，并带一个最小的本地启动安全补丁：
移除上游无条件清理 `.*.old-*` 的调用。补丁路径、来源与刷新流程记录在
[`native/dependency-patches/README.md`](../../native/dependency-patches/README.md)。
构建包装脚本在 build/run/install/test 前检查该补丁，普通 vendor 刷新后
须重新应用，不能依赖模块缓存的临时修改。

## 代价与边界

- 这是已测试原生子集，不是完整旧产品等价物。legacy Tauri 的功能、体积和
  截图仍属于旧路径，不能拿来代表原生路径。
- 去符号 exe 与压缩安装包不是相同口径；本决策不做体积大小排序。
  原生进程工作集、private bytes、CPU 样本与测试器累计分配也须分开记录。
  2026-11-08 18:17字段版已通过全套检查；前一16:45链接副本的隐藏启动
  进程样本已验收为有限证据。原资源矩阵因关闭前20秒未见会话文件仍为FAIL；正常
  关闭后的首次恢复通过，不由此推断绘制帧，也不把非必要重复当独立场景。
  后续字段版不继承该资源数值。具体产物、测量与尚未完成的系统验收见
  [`native/VALIDATION.md`](../../native/VALIDATION.md)。
- 2026-11-08 的 doc-block 本地引用已通过解析器、最终原生视图、真实应用
  适配器、窄窗图片、narrow/clicked-row 来源守卫和 GLM 最终复核。一次完整
  test/vet/build/隐藏启动关闭也已通过，根代理随后接受精确产物；
  其后由 Markdown 管道表第一切片取代为上一验收产物。证据见
  [`native/VALIDATION.md`](../../native/VALIDATION.md)；构建成功与产物验收
  仍分开记录，不以构建成功代替产物验收。
- Markdown 管道表第一切片的解析/导出、原生视图和真实应用聚焦门已通过；
  随后一次全量 test/vet/build、隔离隐藏启动关闭和12/12证据核验通过，
  根代理接受了13,384,192字节的20:49产物。19:20 doc-block引用版转为上一
  验收产物。其后的单元格编辑已通过真实注册适配器聚焦组2.010s、app vet
  和最终视图检查，但根代理聚焦复核与新的完整集成仍未完成，因此当前验收
  产物中不含这项后续源码。状态与边界见
  [`native/VALIDATION.md`](../../native/VALIDATION.md)。
- 低内存、低 CPU 仍是目标。解析、布局和极长文本的冷排版尚有线性成本；
  资源上限是过载保护，不是流畅交互保证。
- 自研编辑与格式内核意味着更多维护责任。只有带测试的有限能力会被写进
  能力矩阵。
- 应用按纯本地路径实现，未启用更新、遥测或外部 URL 打开。Windows
  构建依赖图仍含工具包的 WebView2、更新器等包；包存在与运行时启用必须
  区分。系统网络跟踪及输入法完整验收仍需独立证据。
- 第三方许可通知按实际源码与派生来源保留。MyGo 的 MIT 许可不替代
  purego 的 Apache/BSD 等条件；来源与实际复制的许可文本见
  [`native/THIRD_PARTY_NOTICES.md`](../../native/THIRD_PARTY_NOTICES.md)。

## 重审条件

- MyGo 上游发布安全的启动清理开关或新版本时，重新评估本地补丁，并按
  `dependency-patches/README.md` 换成基于新版本的补丁。
- 自研编辑内核无法在目标文档规模或输入延迟内达标，或维护成本显著超过
  MyGo 允许的替代路径时，重新评估。
- 若目标平台缺少可用的 MyGo 原生 Surface 后端，需要重新评估平台优先级。
