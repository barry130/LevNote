# 轻笺 导出样例

这一段的用途是**目视验收**：把编辑器里的文档导成一个自包含 HTML，
拷到任何一台机器、断网、双击打开，观感应当与编辑器内一致。

## 一、文字与行内标记

普通段落，含 **加粗**、*斜体*、`inline code`、以及一个[外部链接](https://example.com)。
行末两个空格可以制造换行，\
于是这一行与上一行之间只有一次换行。删除线与 GFM 扩展：~~划掉~~、==高亮==不在规范内，这里测的是删除线。

> 引用第一层：自包含的含义是「不依赖外部资源」。
>
> > 引用第二层：不需要样式表、不需要字体文件、不能出现破图。

## 三、表格

| 构件     | 内核负责    | 导出侧负责            |
| ------ | ------- | ---------------- |
| 文档结构   | 是       | 否                |
| 语法高亮   | 装饰（仅视图） | 是（重走一遍）          |
| 图片内联   | 否       | 是（读字节转 data URI） |
| 版式 CSS | 共用同一份   | 共用同一份            |

## 四、代码块

声明了语言，走指定语法：

```typescript
export interface EditorAdapter {
  id: string;
  label: string;
  matches(path: string): boolean;
  canHandle?(path: string, text: string): boolean;
}

export function resolveAdapter(path: string, fallback: EditorAdapter, text?: string): EditorAdapter {
  for (const adapter of adapters) {
    if (!adapter.matches(path)) continue;
    return adapter;
  }
  return fallback;
}
```

没声明语言，走自动识别：

```
SELECT path, session FROM documents
WHERE dirty = 1 ORDER BY opened_at DESC;
```
