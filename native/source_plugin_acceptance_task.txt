- For schema2 verify required/optional/null/type/unknown-field distinctions,

Astra focused checkpoint:
- Literal first full marker match owns the line, even an empty label; only
  horizontal ASCII trim; exactly one terminal CR removed; internal CR retained.
- Byte/rune/UTF16 offsets across short reads, CRLF, Unicode/emoji, EOF and
  budget boundaries. End includes terminator for source identity.
- Reader errors, data+EOF, invalid counts, <=8 zero-progress retries, invalid
  UTF8, huge physical lines and exact byte/line/item caps have finite results.
  Never emit a cut partial line. Report bounded scratch read-ahead accurately.
- Same label duplicates and harmless prefix edits follow exact old range;
  overlap edits, Restore, expired64-edit journal, buffer/rules/plugin changes
  fail stale. Anchor unsupported. Snapshot returns owned slice and Release
  frees descriptors while tiny immutable configuration can remain reusable.
- Report a reproducible large-line/cache microbenchmark or allocation check
  with fixture size; no claims that this measures main-process working set.
- Final docs include real capability/limits and latest accepted artifact only.
