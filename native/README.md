# 轻笺 · LevNote 原生版

这里是 Go + MyGo 的原生实现，也是目前的开发主线。窗口和编辑区使用
MyGo **原生 Surface**，界面不在浏览器页面中运行；文本编辑、Markdown、
思维导图和 draw.io 格式处理由本项目实现。

当前交付是有明确边界的原生子集。根目录 `src/`、`src-tauri/` 及其
Milkdown、CodeMirror、mind-elixir 功能属于旧 Tauri 实现，不能当作本版的
能力清单。迁移理由见 [ADR 0063](../docs/decisions/0063-native-migration.md)。

## 构建与运行

当前构建与验收目标是 **Windows amd64**。打包与构建检查需要 PowerShell 7+
（`pwsh`）；首次下载项目内
Go 工具链还需要 Node.js 20+ 和网络。其他系统尚未完成原生验收。

在仓库根目录执行首次准备；已有 `native/tools/go/bin/go.exe` 时可跳过：

```powershell
node .\native\scripts\bootstrap.mjs
Expand-Archive -LiteralPath .\native\tools\go1.27.3.windows-amd64.zip -DestinationPath .\native\tools -Force
```

下载脚本固定 Go 1.27.3，从 Go 官方发布清单取得 SHA-256 并验证归档，验证
成功后才可解压。工具链、模块缓存和编译缓存放在项目内，不替换系统 Go。

重新构建当前宿主及四个固定worker，输出目录必须尚不存在：

```powershell
.\native\scripts\package-markdown-worker.ps1 -OutputDirectory .\native\bin\worker-build-local -EvidenceDirectory .\native\artifacts\worker-build-local -Version local.1
```

该脚本沿用`package-markdown-worker.ps1`名称，通过固定Go包装器构建Windows
amd64 GUI宿主和Markdown HTML/导图SVG/只读导图场景/draw.io SVG四个worker；
为各引擎生成相邻版本/大小/SHA256清单，并复制完整许可、来源/补丁材料和
便携说明。
输出与证据目录必须均为全新、父目录已存在、互不嵌套的普通本地目录；
相对路径按调用者PowerShell当前位置解析。构建日志、helper脚本和结果仅
保存在EvidenceDirectory，OutputDirectory仅含运行资产和相对路径的
`release-manifest.json`（明确不包含自身）。生成成功不表示产品已验收，
也不宣称跨机器可复现发行包。2026-11-10的`.29`完整目录已通过根代理验收，
新增连续完整IME标记范围的原始/当前端点保留，并继承`.28`普通UTF-8内容增长
准入和大小拒绝IME屏障；`.27`的最近关闭文件重开与
100活动标签准入，以及既有有界PNG/JPEG阅读、图片键盘、明确100%、不依赖
绘制的恢复调度、表格列操作和明确图片引用打开继续保留。
构建、隐藏启动和行为验证的
不同范围，以及精确身份与证据，统一见[验证记录](VALIDATION.md)与
[`.29`交付](handoffs/composition-release29-delivery.md)。
历史包、失败证据和修正记录见[验证记录](VALIDATION.md)。
普通 `go build ./cmd/levnote` 仅生成宿主，缺少对应相邻worker时HTML/导图
SVG导出或只读场景预览会明确失败；源码仍可查看，不会静默改用宿主解析。

运行本次已验收交付，也可以传入本地文件路径：

```powershell
.\native\bin\levnote-native-worker-20261110.29\levnote-native.exe
.\native\bin\levnote-native-worker-20261110.29\levnote-native.exe 'C:\Notes\说明.md' 'C:\Notes\图片.png'
```

测试与静态检查分别执行：

```powershell
.\native\scripts\go.ps1 -GoArguments @('test','./...','-count=1')
.\native\scripts\go.ps1 -GoArguments @('vet','./...')
```

这些命令使用 `native/vendor/` 中固定的依赖。MyGo 的启动安全补丁是构建
条件；包装脚本会拒绝缺失补丁或绕过 vendor 的构建。需要重新生成 vendor
时，执行 `native/dependency-patches/refresh.ps1`，其来源、范围和验证方式见
[补丁说明](dependency-patches/README.md)。直接运行 `go mod vendor` 会覆盖
补丁，随后必须重新应用，不能将模块缓存里的临时修改作为构建输入。

包装器在调用期间使用`GOWORK=off`、`GOENV=off`，隔离外部工作区和持久化
Go配置；调用结束恢复原环境值，不改用户机器设置。显式参数与GOFLAGS中
改变目录、modfile、overlay或非vendor模块模式会拒绝。Go参数按实际大小写
处理，`test -c`可正常生成测试程序，`-C`仍拒绝。它是固定构建上下文检查，
不是不可信源码/进程的安全边界。

对最近关闭文件重开，工具字段仍在组合输入时同样提示先完成或取消，再明确

Markdown HTML、导图SVG和draw.io SVG共用一个导出任务槽，显示进度与取消按钮。四个
worker共用单执行队列：最新待处理预览替换旧预览，导出优先，等待旧进程

同步草稿，再读取不可变快照；worker 处理期间可继续编辑。结果返回及保存
位置对话框关闭后都会再次同步、核对文档版本，期间已改动（包括编辑后
撤销）会拒绝发布并提示重试。切换标签、关闭文档或停用格式会取消任务；
关闭应用须等待所属进程清理，清理失败会保留文档及草稿并说明原因。
选择目标后沿用不覆盖已有文件的写入规则，最终写文件仍在 UI 线程执行，
开始后不能取消。只读文档也可导出；源文件及编码不因导出而改写。

这些固定worker仅在导出或只读预览时按需启动，结束后退出；源码模式导图无需
创建画布。Markdown源最多8MiB，导图源最多16MiB，输出各最多64MiB，
默认全请求超时30秒。导图SVG共用当前原生布局/颜色/有界标签，图片仍是
「图」占位，不读取图片或联网。导图警告使用整份源码范围，不代表精确
节点位置；警告超过256项或元数据字节上限会拒绝，不静默截断。

draw.io当前页SVG由第四固定worker生成，序列化输出也有64MiB硬限。直接API的零值使用
默认上限，较小正数收紧上限，超过硬限的正数夹取，负数拒绝；无效页码先于
输出预算报错。生成器先有界计数，再按精确大小分配一次输出缓冲；超过上限、
计数/填充不一致或其它失败都不返回部分SVG或问题列表，现有导出错误界面
显示失败。恰好填满上限的成功结果仍保留原有SVG字节、警告顺序和所选页。
该上限只约束序列化输出字节，不是进程内存限制：源文、解析/页面索引、
警告和点序列以及成功结果缓冲仍占内存，两遍输出也会重复部分几何工作。

只读思维导图使用独立场景视图，支持选择、缩放、平移、适应和可见节点
大纲定位；隐藏节点不会因定位而改写折叠状态。节点属性、备注、链接、
标签和图片引用请到源码查看/复制，需要编辑时先另存为可写副本。切换源码
本身不会解除只读，SVG导出仍可直接使用。此场景不加载或显示图片，也不
画图片徽标；SVG和可编辑画布的「图」占位行为保持。缺失/损坏引擎或场景
失败会显示原因和源码入口，不改用宿主解析。场景DTO最多32MiB，不是RSS
上限；字面颜色保留，无法保证任意文档颜色与所有主题的对比度。

### 本地图片阅读

`.23` 内置本地PNG/JPEG只读图片模式，`.24`补充键盘操作；可在格式插件
配置中启用或停用。
打开、重载、解码和复制操作逐项执行并核对来源；不能解码但仍可读取
原始字节的文件会回退到字节视图，读取失败如实报告，不保证不可访问
文件的内容可检查。

- 源文件不超过16 MiB，单边不超过8192像素，总像素不超过8,388,608。
- JPEG支持baseline SOF0、8位、灰度或标准三通道色；不支持CMYK或
  progressive。
- PNG支持不超过8位、非交错、非动画。
- 支持适应窗口、100%（一个图片像素对应一个DIP）、缩放和平移。图片
  画布获得键盘焦点时，可用`+`/`=`/`-`和数字键盘加减缩放，方向键平移；
  `0`进入适应，`1`进入明确100%。明确100%在窗口大小变化时保留该手工
  缩放，按`0`切回适应。激活已启用的工具栏缩放/适应/100%按钮后，
  键盘焦点返回图片画布；仅聚焦工具栏不是动作。「另存副本」把已核验
  的原始字节复制到新目标，不覆盖已有文件，不转码。
- 不提供图片编辑、动画、外链读取或SVG图片路由；超限或拒绝都明示，
  不切换成看似成功的部分内容。
- 超过16 MiB的文件保留有界字节检查，但不能经该路径使用有界图片复制
  操作。
- 会话恢复保存路径、顺序与活动状态；恢复时重新读取保存的路径，不保存
  图片字节或像素。编辑后约900毫秒静默由应用计时器写入恢复状态；调度
  独立于绘制，但原生对话框或重UI工作可能延后本次写入。它从不自动写回
  原文件；尚未显式完成的格式本地草稿仍不在自动捕获内，继续通过完成、
  放弃或恢复流程处理。带图片后缀但已有文本草稿的内容仍按文本处理。

以下字段、标记和标签操作适用于可编辑思维导图。备注是纯文本，保留换行
和尾随空格。属性输入框确认组合输入后，Tab进入属性操作、Shift+Tab
返回字段按钮，F6前往标签面板；聚焦按钮后 Enter/Space 激活。普通节点选择保留
当前字段，双击节点或新建子/同级主题会转到主题文本。

仅查看缺失的备注不会写入空字段；清空已有备注保存为显式空字符串，清空
链接则移除链接字段。切换字段前先写回当前草稿；同一源字段发生变化时保留
草稿并提示冲突。每次实际写回是一条可撤销事务，无改动的保存或导航不增加
历史。「写回并打开链接」只打开这份草稿成功写入的完整目标；清空后不会打开。

标记面板提供19个固定字形：优先级1–9、六种色标、四种符号。优先级和
色标各自互斥，符号可多选，重复点击同一字形取消；词表外字形及其顺序、
重复项照原样保留。「清空全部标记」也清除自定义字形，并保存显式`[]`。
面板默认收起，摘要最多512 UTF-8字节；完整内容在源码中。操作先同步
已有字段草稿，再重验目标和候选；冲突、只读或超限时不提交标记事务。
节点图片仍为占位，未提供图片编辑面板。

标签面板默认收起，位于节点主要属性和结构控件下方，可滚动查看。新标签
必须是非空单行UTF-8文字，最多512字节；空白、逗号、Unicode与重复文字
按输入保存，不trim或拆分。已有空字符串、同名与对象标签按原顺序显示，
「移除第N个标签」只删该序号；全清和最后一项移除保留显式`[]`。对象标签
及未知元数据保留，当前没有对象样式编辑、重命名、重排或全局标签检索。
实际修改仍有JSON重新排版边界，未修改、拒绝和无操作保存保留原字节。

未添加的输入会阻止保存、导出、切换、关闭等操作，请使用「添加标签」、
「放弃输入」或「恢复输入为新文档」。恢复可同时带出未写回节点字段和标签
输入；待添加标签只保留在当前运行窗口，不承诺写入会话/崩溃恢复快照。
Add先写回已有节点字段，再提交标签，各是一条撤销；若字段已写回而标签
被拒绝，会明确说明，字段仍可单独撤销。组合输入未确认时F6/Tab/Shift+Tab
保持当前输入，确认后F6到添加操作。恢复按钮在窄窗口可滚动到达。

简单无序/有序列表开头的 `[ ]`、`[x]`、`[X]` 会显示任务方框，后面须是
空格、制表符或该项结尾；空任务也可切换。点击方框只修改标记中间一个
字符，保留行尾、编号和其余原文；点击任务文字仍可选择或双击编辑列表。
切换前先同步草稿，目标已改变或当前解析不完整时会拒绝并说明。只读预览
禁用方框；HTML 导出中的方框始终不可交互。缩进/嵌套任务和续行规则没有
在这一子集中扩展。

阅读/分屏中的行内链接通过宿主打开本地文档或当前文档标题锚点；只读预览
也可导航，Space 保留滚动行为。空标签用「（空链接）」显示。点击先同步
草稿，再核对原文范围和完整目标；目标已修改、被围栏包住或历史过期时
会拒绝，避免同名链接误跳。源码模式仍直接编辑 Markdown 文本。

显式 `mode: reference` 且 `src` 非空的 doc-block 提供「打开引用」按钮。
按下时会记录 Buffer/版本、预览行、整块与属性区的 UTF-16 范围以及完整
目标；释放/激活先 Flush，再按范围日志重解当前原文。目标自身、引用头或
构造被改写、历史过期、解析不完整或超过 8 MiB 时会可见拒绝，不退回到
同名 ID、标题或列表位置。只读引用也可打开，不增加编辑历史；宿主同步切换
标签并释放当前视图是允许的。完整目标最多 4096 UTF-8 字节，超限按钮禁用；
标题副本最多 256 字节，kind/mode 各最多 64 字节，tooltip 连同前缀与
省略号总计最多 512 字节，均做 UTF-8 安全省略。宿主缺少打开能力时也显示
禁用按钮和可见原因；结构无效的块不显示按钮。
普通 `mode: inline` 即使结构有效也不会当引用导航；带 `src` 的 inline
块会明示该目标不会被打开。

### Markdown 图片引用

`.26` 新增明确的本地 Markdown 图片引用打开。原始 `![label](target)` 语法
保持可见，不会被渲染成内嵌图片，也不引入图片缓存。阅读/分屏中通过
`Ctrl`/`Cmd`+点击或聚焦后 `Tab`+`Enter` 可显式打开目标。打开复用当前本地
文件打开、读取器和字节回退路径；PNG/JPEG 大小/格式边界与图片阅读器启停
不变。目标为 1–4096 UTF-8 字节，排除 ASCII 空白/控制字符、尖括号和
圆括号；标题式（`![alt](src "title")`）和引用式（`![alt][id]`）图片形式
不支持。格式层原样传递目标，本地相对路径、百分号编码和 Windows 反斜杠
保留；已有显式 `file:` URL 和标题锚点继续遵循原有宿主规则。缺失或不可读
目标会如实报告；若原始字节仍可读取，可通过字节回退建立标签。HTML 导出
保留转义后的原 Markdown 文本，不解码图片。

Markdown 管道表格的第一切片识别 1–8 列的矩形表头/分隔行/正文子集。宽度
足够时显示原生网格，较窄时把每个物理行显示为带列名的堆叠记录；单元格
保持字面源码，预览省略会明确提示到源码或整表编辑器查看完整内容。表头与
分隔行存在、正文为零行时也是有效表。可写文档可从「编辑表格源码」打开
完整表块的独立源码草稿；激活和执行后的保存/切换一样先 Flush，再按
Buffer、版本、整表范围与当前解析重验旧目标，失败时保留草稿与恢复入口。
只读文档显示「只读表格」和源码提示，不创建编辑草稿。

单元格面板还提供「前插列」「后插列」和「删此列」，保持
1–8列。操作从权威源码规划精确补丁，保留幸存单元格原始字节、填充、
分隔线写法、缩进、行尾和相邻内容；仅在需要边界时添加外层管道。若单元
格已有修改，先作为单独一步写回，列结构补丁再另记撤销。组合输入确认后
按 F6 进入首个行操作，再用 Tab/Shift+Tab 切换到列/对齐按钮，Enter/Space 执行。模糊尾随转义、
过期/不规则/不支持目标或预算变化均拒绝补丁；拒绝时可见说明，整表源码
编辑仍是完整回退。

超过 32 KiB 的表不构造完整预览，显示有界源码指引；完整 `Block.Raw` 仍是
文档依据，现有双击块编辑可打开整张表。单单元格编辑只改一个格子的完整
字面源码；现在另有下述数据行、所选列对齐和列增删操作，仍无排序、合并、公式或嵌套表，也不承诺完整
GFM。反引号内的未转义管道仍按结构分隔符处理。HTML 导出把有效表导出为
文字语义表格，并把
单元格 Markdown/HTML/链接按字面转义；无效或超限表导出完整转义原文。

表格第二切片让表头和数据单元格成为可聚焦的原生目标，双击或 Tab+Enter
可在一个独立原生编辑器中修改该单元格的完整字面源码。输入先只留在视图
草稿中，不立即改宿主 Buffer；完成编辑、保存或切换前统一校验并最多写回一次。
结构管道、换行、4096 字节单元格草稿和 32 KiB 表等限制失败时保留草稿，
可继续修改、放弃或打开未同步副本。只读单元格不创建草稿。未完成写回的
单元格值不进入自动会话/崩溃快照，必须在提示的保存或完成编辑动作后才会
成为文档内容。

选中单元格的面板提供「在下方插入行」「删除此数据行」。表头插入位于分隔
行之后，表头自身不能删除。新行保留选中行缩进与插入位置的行尾风格，
删除仅移除那条物理数据行；其他源码字节保留。若单元格有修改，会先写回
单元格，再把行操作记为另一条撤销；未改动的单元格只需一次行撤销。
单元格写回失败时保留可恢复草稿；写回已成功但行操作被拒绝时会明确提示，
已写回内容仍可单独撤销。行操作沿用8列、256正文行、4096字节单元格、
32KiB表和8MiB源限制，并检查全篇16,384个描述项预算；不能让别的表从正常
预览变为回退，也保守拒绝删除后使别的回退表变为可预览的操作。

面板还显示所选列和当前对齐，并提供「默认 / 左 / 中 / 右」。修改只替换
分隔行该列的非填充标记：改变两端冒号，保留原短横线数量、空白、管道、
其它列/单元格与行尾。成功和相同对齐的无操作都会完成并关闭单元格面板。
干净同对齐不改源码、选区、历史或脏状态；有单元格草稿时先写回，真实对齐
另记一次撤销，同对齐则只保留单元格自己的撤销。写回失败保留恢复入口；
已写回而对齐拒绝会明确说明，写回仍可撤销。源码选区落在被替换分隔标记
内部时移到标记起点，其余选区按补丁映射，说明见按钮提示。

单元格输入框中的 Tab 仍用于编辑。确认输入法组合后可按 F6 到表格按钮，
再以 Tab/Shift+Tab、Enter/Space 操作；组合尚未确认时 F6 保持焦点与草稿
并提示先确认。控件拒绝打开面板手势的连续多击和重复按键，避免紧接着
误改表。两张760×480分屏集成测试器截图已验收，完整48px输入以及恢复、行、
对齐按钮均位于真实状态栏上方；键盘提示可用Escape关闭，焦点仍可Enter执行。
这不是物理系统IME或所有指针序列的验收。本轮未对`.5`进行资源对照。

Markdown 大纲列出当前解析器识别的标题，支持 Unicode 与重复标题；阅读模式
滚动到标题，源码模式定位标题语法起点，分屏同时定位两边。导图大纲包括
折叠节点；定位隐藏节点会展开其祖先，作为一次可撤销的文档修改。只读文档
不能自动展开隐藏节点，源码模式下的导图会提示切到阅读或分屏，应用不会
替你切换模式。分屏导图导航保留有效的源码选区；重新序列化使原偏移失效时
会夹取到合法字符边界并提示。列表高亮表示当前选择/快照提示，不持续追随
源码光标移动。

安装了 schema2 字面规则配置的源码格式也可提供大纲，例如 INI 的 `[节名]`。
它只在源码中定位，没有阅读/分屏图形视图或富导出。规则逐行匹配，不跟踪
多行注释、字符串或代码块，因此这些区域里的同形文本也可能进入大纲。

仅接受十六进制或命名纯色，其他色值保留原文并提示使用默认色。

`.21`收窄draw.io结构容器告警：新建空图纸不再报告两条泛化容器告警；只有
按顺序出现的精确0/1空容器对被识别为规范容器，XML空白和注释不影响判定，

[验证记录](VALIDATION.md)。

格式编辑也有序列化边界：未修改的文件按原字节保存；修改导图结构或字段
后会重新排版 JSON（默认两空格、LF），保留未知字段而不保证原来的空格
和键排列。直接在源码编辑器修改时则保留未改动的文本。

缺少必需 `---` 分隔符的 Markdown doc-block 会警告并显示完整原始代码；

不提供嵌套图表编辑器。解析器先把键名归一化为小写，再识别规范键
`id/kind/mode/src/title`；值沿用既有 `TrimSpace` 规则。重复识别键、
无效/缺失 ID、缺失 kind、未知/缺失 mode、reference 模式缺少 src 和
未闭合围栏产生有界诊断。相同 ID/标题不代表全局唯一，导航身份是精确
源码范围。解析器的
`ReferenceProblem == ""` 只表示结构可用，不表示目标存在、允许打开或权限
可用。

## 本地数据与插件

配置写入 `os.UserConfigDir()/LevNoteNative`，Windows 通常为
`%APPDATA%\LevNoteNative`。会话是 `session.json`，插件偏好是 `plugins.json`，
安装的配置位于 `plugins/`。这些文件仅在本机保存。

插件面板可安装本地 JSON 文件、启停、重新扫描并查看加载错误。
schema1 配置声明扩展名、注释标记和关键字；schema2 还可声明最多 8 条
字面前缀/后缀大纲规则。schema3可选择固定的Markdown、思维导图或draw.io能力。
配置不提供脚本、动态库、进程启动
或联网钩子。内置 Markdown、导图、图纸和代码格式均可停用；所有候选均
不匹配时仍保留纯文本入口。配置格式、优先级和 `InstallFile` API 见
[格式与插件 API](formats/API.md)。

随包Markdown HTML、导图SVG、只读场景和draw.io SVG引擎是项目维护的四个固定程序，与
可安装JSON配置分开。schema1/2仅扩展源码高亮/大纲；schema3复用所选格式的
原生能力并保留只读限制。Markdown/导图路由提供编辑、大纲及导出；draw.io
路由提供编辑、预览和当前页SVG，没有大纲或只读场景。停用配置后按剩余配置重新匹配；
落到源码兜底时不保留旧配置的导出或场景执行能力。
插件面板的导出状态在首次导出前显示「未检查，导出时验证」，以后展示最近
导出结果及已验证的版本/摘要；场景加载/失败显示在只读视图。这个懒检查
状态只描述最近一次实际请求，不启动或扫描worker。

### 本地引擎包

「插件 → 引擎包」中的「本地引擎包」面板一次管理一个固定引擎：Markdown
HTML导出、导图SVG导出、只读导图场景、图纸SVG导出。选择本地发布目录后，应用只导入
该引擎的必需文件与许可证，校验版本、大小和SHA256；导入完成后显示为已
安装，但不会改变当前选择。启用、恢复随包和重置全部选择都是明确
动作；面板显示当前来源、版本、摘要与错误，重复导入相同digest会重新
验证既有安装并原样复用，不新增、不覆盖。

导入/启用在后台执行，面板隐藏后仍可在打开的文档中重开并查看进度，可
取消。已安装包存放在 `%APPDATA%\LevNoteNative\engine-packages`；每个
引擎最多保留12个版本。应用不提供删除版本、任意可执行路径或引擎插件
API。已安装包列表与导入会验证包文件；随包选择仍按实际请求验证宿主目录
中的固定文件。查看任意列表都不会启动worker。校验和只验证本地副本字节
一致，不证明发布者身份，也不是沙箱；显式启用后的包会在实际导出/预览
请求中启动对应本地worker。

schema1/2/3是本地JSON格式配置，与引擎包分开。schema3只选择固定
Markdown/导图/draw.io适配器，不能安装或配置可执行worker。

可从插件面板安装仓库内的 [INI 示例](examples/plugins/ini-outline.json) 或
[配置标题示例](examples/plugins/config-headings.json)。源码仍由自研文本
编辑器编辑和保存，列出/定位不会改写文件。具体内置格式优先于安装配置，
可以先停用内置格式再使用覆盖其后缀的配置。schema2字面大纲不提供链接锚点。

要让自定义后缀使用原生格式，在“插件 → 安装”选择
[task-notes.json](examples/plugins/task-notes.json)、
[thoughts.json](examples/plugins/thoughts.json)或
[diagram-notes.json](examples/plugins/diagram-notes.json)。三者分别让
`.taskmd`使用Markdown、`.thoughts`使用思维导图、`.diagramnote`使用draw.io；
面板显示对应原生格式和“新建文档”。draw.io示例要求文件正文本身是draw.io
XML，不把其他格式转换成图纸。便携包README也内嵌三份完整JSON，可另存后安装。

“新建文档”使用第一个规范化后缀（补点、转小写、去重）与对应模板。
若该后缀被更早的配置匹配，明确拒绝，不尝试后面的后缀。配置身份
`task-notes`/`thoughts`与原生适配器`markdown`/`mindmap`分开，各配置独立
启停，不依赖同名内置配置的开关。禁用后仍可查看未匹配文档的源码；
可写文件仍可编辑保存，只读文件需另存为可写副本。

另存为按新路径重新匹配，**不转换正文**：把Markdown保存为`.thoughts`
不会生成合法导图。安装、禁用、新建和另存为都先处理已有草稿；对话框
返回后再次同步并核对来源。失败或待添加标签会保留输入并拒绝操作，请
按面板完成、放弃或恢复。启用偏好写入失败保留当前视图；偏好已写入而
配置文件丢失/损坏时，明确显示加载失败并按实际可用格式刷新。

打开相对引用时以已保存文档的目录为基准，不借用进程工作目录。原生应用
拒绝网页 URL、邮箱协议、远程 UNC 和带主机名的文件 URL；锚点仅在视图
支持时可用，Markdown 标题锚点与 HTML 导出使用相同的 Unicode/重复标题
规则。导图没有 Markdown 锚点。导出的 HTML 是独立文件，其允许
的相对链接、锚点和 `mailto:` 链接由之后打开它的程序处理。

当前相对引用按字面文件名处理，不把 `%20` 自动解码为空格，也不把本地
文件名的 `#`/`?` 拆成目标文件锚点或查询。支持本地绝对 Windows 路径、
解码一次的本地 `file:` URL 和当前文档 `#锚点`；未保存文档的相对引用
会拒绝。链接标题语法、跨文件片段定位和更广的 Markdown 链接语法未扩展。

## 大文档与资源限制

限制会显示提示，完整源码仍是文档依据。它们控制资源增长，不代表接近
上限的文档已经达到流畅交互标准。

- 文本编辑的源文件读取上限为128 MiB；`.28`另在文本层限制普通UTF-8实时
  逻辑内容为128 MiB，两道边界相互独立。初开或显式重载的已解码种子即使更大
  也完整保留；编辑高水位固定为`max(基值,种子字节数)`，缩小后仍可增长回该值，
  撤销/重做/取消可回到已接受状态。替换、ReplaceAll和缩进在提交前检查，拒绝
  不留部分命令；反向ReplaceAll的中间状态超限时可保守拒绝最终可容纳的批次。
  格式字段写回拒绝保留本地草稿，可缩短后重试或另行恢复。
- 大小拒绝的IME组合输入保持待处理；保存、切换视图/标签或关闭须等待有效
  重试，或用户在编辑器中按Esc明确取消。焦点丢失不能替用户提交或清除拒绝；
  重新聚焦后完成上述动作再继续。被拒绝字符串不复制、不保存，普通粘贴拒绝
  不形成永久屏障。这个128 MiB逻辑内容界限不是进程内存或全部文档上限；
  剪贴板、正则展开、编解码临时串和当前活动组历史仍单独占内存。`.29`为
  连续完整IME标记范围保留原始/当前历史端点；非连续或不规则显式范围仍按
  普通后缀追加，不能据此宣称通用历史上限。超长源码行超过4096个UTF-16单位
  时按2048单位分段。
  Markdown草稿与节点字段使用更小的排版段；导图属性输入采用512单位排版预算
  和可滚动区域，完整字段仍可编辑/复制。
- Markdown 解析上限为 8 MiB、65,536 行、8,192 块、每列表 4,096 项、
  16,384 行内 span 和累计 1 MiB 行内扫描；触发任何解释预算会设置
  `Partial`，提示切到源码并拒绝不完整 HTML 导出。
- Markdown独立导出输入最多8MiB、导图SVG输入16MiB，结果各64MiB，默认
  全请求30秒超时；警告
  和错误长度也受限制。当前渲染器先在预算内计数，再一次分配精确HTML
  缓冲并填充，超限不返回部分结果。64MiB约束输出缓冲，不是进程峰值
  内存保证或流式承诺；源文/解析结构、宿主结果副本等仍占内存。
- 导图默认解析上限为 16 MiB、100,000 节点、256 层；图纸默认为
  32 MiB 输入、64 MiB 累计解压内容，并有 XML 深度、元素和属性限制。
  这些是拒绝过载的解析保护值，不是已验收的流畅画布规模。
- 只读导图源16MiB，场景DTO32MiB，至多100,000节点/99,999边，ID512字节，
  标签最多512字节摘要加可选3字节省略号。每帧最多256个标签布局并使用
  256项缓存，缩小/预算隐藏会明示；这不是全部节点始终可读的承诺。所有
  worker警告最多256项、每项message512字节，响应元数据1MiB；整篇范围
  不表示节点精确源码位置，超限拒绝不截断。这些预算都不等于进程RSS。
- 宿主解析的三类富视图在复制整篇源码前检查字节上限；超限时清除旧预览，显示
  源码入口提示并拒绝导出。源码缩回上限内或重新载入可恢复预览。独立
  草稿保留：Markdown 范围仍有效时可同步局部文字，图形节点因必须解析
  整份模型才能写回而拒绝超限同步，可将草稿恢复成新文档。
  只读导图场景请求同样先查源预算；已显示场景的更新失败可保留旧图，
  明示“旧预览未更新”并拒绝旧节点导航，不把旧图当作当前源码。
- 会话最多 100 个标签，单草稿 4 MiB，整个编码后 JSON 16 MiB。快照校验
  与预算在目录或临时文件动作前完成；标准`json.Encoder`经适配器写入既有
  原子临时文件，运行期核对预检长度、拒绝短写/溢出，并只移除末尾强制LF。
  完整JSON字节、字段、转义和无末尾LF格式由测试与旧`json.Marshal`oracle
  逐字节比对；Encoder仍内部缓冲完整JSON，脏草稿字符串捕获也不变。写入、
  发布前校验或发布操作失败保留旧恢复文件；发布成功后目录同步失败会返回
  错误，但新文件已生效且不回滚。无法保护的草稿会明确提示，现有重试/丢弃
  行为不变。
- 工作区树最多显示 3000 条、每目录 256 条、深度 12；搜索默认每文件
  4 MiB、遍历 10,000 条、2000 个结果。省略和跳过都在界面说明。

它增加一个紧凑的源码行列导航面板。输入严格为正的ASCII`line`或
`line:column`；省略列时为1，前导零、零、符号、空值、多余分隔符和溢出
都会在原处拒绝，不夹取。输入最多32个UTF-16码元。坐标是一基UTF-16码元
位置；CR/LF不计列，末尾空行有效，代理对内部列拒绝，组合码点之间仍可定位
但不是字形簇语义。提交时先解析输入语法，再通过普通Flush同步当前视图输入，
随后重验捕获的标签/文档/编辑器/Buffer；行列范围只在Flush后的最终缓冲上
验证。

源码/分屏保持当前模式，预览只有在最终目标有效后才切换为源码。所有成功
导航请求保存位置。只读源码可导航，已显示的只读十六进制字节视图也可用，
面板会明确说明目标属于字节视图。打开时源码编辑器或任一中性富视图的
组合输入会阻止导航；提交时只有导航查询字段自身的组合输入会阻止。
当前面板代际、输入键和回调共同阻止关闭/重开后的旧动作，标签选择、
新/恢复标签、重载、编码重匹配和插件重配会清理旧目标。Flush拒绝保留
面板、原始查询、草稿、选区与历史；Flush成功但目标无效时会明确提示
文本已经同步。
