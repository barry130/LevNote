# 轻笺原生版 · Windows amd64

在本目录双击 `levnote-native.exe`，或用 PowerShell 运行：

```powershell
.\levnote-native.exe
.\levnote-native.exe 'C:\Notes\说明.md'
```

Markdown HTML／思维导图 SVG／draw.io SVG 导出引擎和只读思维导图场景引擎版本：`native-worker.20261110.26`。请整体保留本目录的 `engines/`、
`licenses/`、`attribution/` 和说明。配置/会话/本地JSON语法配置位于
`%APPDATA%\LevNoteNative`；移动程序目录不会移动用户数据。本目录不是
自包含用户配置的便携模式。

恢复快照在最后一次源码编辑静默900毫秒后自动保存；标签与偏好变更沿用剩余
等待时间。调度独立于绘制，窗口隐藏时也可经主线程执行，主线程繁忙或原生
对话框会延后写入。恢复快照不会自动保存到原文件；格式面板中尚未写回文档的
本地草稿仍须按提示明确完成。正常关闭会另行保存恢复状态，写入失败会提示。

MyGo原生UI在宿主进程内绘制界面。Markdown HTML、思维导图 SVG 与
draw.io SVG各使用一个固定的一次性导出worker；可编辑思维导图和draw.io
图谱的解析/编辑仍由宿主处理，源码大纲解析也留在宿主。只读思维导图预览
由 `levnote.mindmap-preview` worker解析/布局，生成有界场景DTO，宿主内
原生UI直接绘制该DTO，不使用WebView，也不会改用宿主解析或布局作为回退。
draw.io SVG worker只导出当前选中的页面，并校验该页的索引和ID；源码模式
不提供draw.io导出，请先切换到可见的“阅读 / 编辑”或“分屏”模式并选中页面。
找不到页面或页面身份变化时会明确失败，不会静默改用第一页。

worker仅在需要时启动，完成或取消后退出；源码模式导出思维导图无需创建
画布。请保留 `engines/markdown-export/`、`engines/mindmap-svg/`、
`engines/mindmap-preview/` 和 `engines/drawio-svg/` 中各自的程序和清单。
导出显示进度和取消；预览缺失或损坏的引擎会显示失败，可切换源码模式查看
原文。来源变化或缺失/损坏引擎会明确拒绝，不会静默回退到进程内导出。
宿主交给worker的是当次源文本的本地不可变快照；worker不读取或改写原始
文件。导出不覆盖已有文件，最终写入同步执行，开始后不能取消。

Markdown 源8MiB、思维导图源16MiB、draw.io源32MiB，各导出结果上限
64MiB，默认30秒。导出输出先在预算内计数，再按精确长度一次分配结果并
填充，超限不返回部分文件。draw.io警告最多256项，代码、消息和单元格
元数据也受固定字节上限约束；超限会明确拒绝。上述是输出缓冲限制，
不包含源文本/解析结构等内存，也不是进程大小、进程峰值内存或流式保证。
只读思维导图预览源码上限16MiB，场景DTO上限32MiB；布局、颜色和有界
字面标签由场景worker计算，宿主只负责绘制。

只读场景支持缩放、平移、节点选择与大纲导航；节点属性、标签和图片引用
请在源码中查看。需要修改时先“另存为”可写副本，随后可使用可编辑导图
的属性面板；切换源码本身不会解除只读。SVG导出仍可直接使用应用的
“导出”按钮，不必切换视图。下方标签编辑说明仅适用于可编辑思维导图。

思维导图 SVG 导出沿用节点图片的“图”占位；只读场景预览不加载或显示
图片，也不显示该占位徽标，图片引用仍完整保留在源码中。两者都不读取
图片文件或访问网络。未知字段和原始源码保持不变。
draw.io导出警告的源码范围覆盖整份源码，页面内问题也在警告消息中标明页面
或单元范围；这不表示能用警告定位到精确节点。警告超过256项或元数据字节上限
会明确拒绝，不静默截断；draw.io SVG由上述独立worker导出当前页面。

原生图片阅读器以只读方式显示 PNG/JPEG；“图片”模式支持“适合窗口”、
“100%”、减小/增大、按指针缩放和平移。100%表示一个图片像素对应一个
DIP，明确选择后调整窗口仍保留实际大小；“适合窗口”显示完整图片，必要时
可小于手动缩放下限。图片区域获焦后，`+` / `=` 或小键盘加号放大，`-` 或
小键盘减号缩小，`0`适合窗口，`1`实际大小，方向键每次平移32 DIP。明确操作
可用的缩放工具栏按钮后，焦点返回图片区域；“查看字节”进入只读字节视图。
图片不会转码或
写回原文件，“另存副本”把已核验的单图原始字节复制到新位置，不覆盖已有
目标；无法显示或被拒绝时，可在“字节视图”中检查仍可读取的原始字节；
源文件无法读取且没有已载入快照时会报告失败。可在“插件 →
格式配置”中启用或停用内置图片阅读器；停用后保留只读字节检查入口。
会话恢复只保存绝对路径等元数据，并保留标签顺序与当前项；恢复时会重新
读取保存的绝对路径，不保存像素、源字节、缩放或平移。

Markdown 中的单行 `![标签](目标)` 是显式图片引用：Ctrl/Cmd+点击或 Tab+Enter
交给既有宿主打开路径。预览不自动载入目标图片；主动点击后才进入现有
打开流程。PNG/JPEG 使用上面的只读图片阅读器及同一组限制，可读但不支持的
文件可继续使用既有字节检查入口。目标必须为 1..4096 UTF-8 字节，且不含
ASCII 空白（空格、制表符、换行等）、控制字符、尖括号、圆括号、标题或
引用式语法；嵌套可操作语法不会因此多出一个图片动作。图片引用本身不渲染
内联像素，也不获取网络资源。格式层把目标文本原样交给宿主；普通本地相对
路径保留原始 Windows 反斜杠和 `%xx`，并原样传给宿主。格式层不反转义或
百分号解码。既有宿主只对显式 `file:` URL 和锚点执行自身原有的解码规则，
不能据此推导其它目标会采用相同解码。
HTML 导出保留转义后的原始语法，不生成 img 元素，也不读取或获取图片资源。缺失或不可读目标会报告失败；
普通外层链接、源码字节以及没有图片载入时的只读检查入口保持不变。

当前图片子集限制为不大于16 MiB的源文件、任一边不大于8192、总像素不超过
8,388,608；JPEG仅支持8位baseline（SOF0）的灰度或标准三通道图像，不支持
CMYK或渐进式JPEG；PNG须为不超过8位、非隔行且非动画。
不在子集内的 PNG/JPEG、损坏文件或其它格式会明确失败并保留字节检查入口；
源文件超过16 MiB时，可读取的文件仍可做最多64 KiB的有界字节检查，
但不能使用“另存副本”复制图片原始字节。不支持动画、编辑、重新编码、外链或
SVG图片路由。图片的读取、解码和
复制一次只进行一项；切换标签会释放非当前图片已载入的像素，但正常打开、
重载或“另存为”原生对话框期间，旧图及旧源文件可能在替换读取被采纳或对话框
结束前短暂保留。这些生命周期不构成进程RSS/VRAM峰值、瞬时回收或GPU资源
保证。

支持的 Markdown 表格可双击单元格进入编辑，在单元格面板中插入或删除
数据行；表头只能在分隔行后插入。面板显示所选列和当前对齐，可按
“默认／左／中／右”修改该列，仅改变分隔行中这一列的冒号，保留原有
短横线数、空白、管道符、其它单元格和行尾。成功或相同对齐的无操作
都会结束单元格面板；无待写单元格修改时，相同对齐不改源码或撤销历史。
键盘操作先确认输入法组合；光标位于单元格时按 F6，先聚焦当前行的第一个操作，随后用 Tab/Shift+Tab 移动，Enter/Space 执行。
行按钮下方的“前插列／后插列／删此列”
可在当前列前后插入空列，或删除当前整列；表格保留1至8列，到达边界时
相应按钮禁用。保留单元格的原始字节、空白、对齐标记和行尾，仅补充必要的
边界管道符；不重新排版整张表。单元格有修改时先写回，列插入／删除、
列对齐或行变更另记一次撤销。单元格写回失败时保留可恢复草稿；若单元格
已写回而结构或对齐操作被拒绝，已写回内容仍可单独撤销。单元格写回后
对齐无操作只保留单元格的撤销。无法保留原始内容、超限或不支持的表格
会明确拒绝操作，可编辑完整表格源码；尚无排序或新增表格语法。

可编辑思维导图选中节点后，在主要属性下方展开“标签”。可添加非空单行 UTF-8
标签（最多512字节），按序移除同名/空字符串旧标签，或清空为 `[]`；
对象标签和未知元数据随其它标签保留。面板最多处理64项、8KiB保留内容
预算，超限请用源码。实际修改会重新序列化JSON；未修改/拒绝/无操作
保存仍保留原字节。节点字段与标签修改分别撤销；字段已写回而标签被
拒绝时，字段仍可单独撤销。

尚未添加的标签不会随保存、导出、切换或关闭自动加入。请明确“添加
标签”、“放弃输入”或“恢复输入为新文档”；恢复会包含尚未写回的节点
字段和标签输入。待添加输入只保留在当前运行窗口，未承诺进入崩溃恢复
快照。组合输入先确认，再按F6进入操作；面板可滚动。画布/SVG仍显示
有长度上限的字面标签，未新增对象样式编辑、重命名、重排或全局检索。

“插件”面板包含“格式配置”和“引擎包”两个页面。在“格式配置”页面可选择
本地JSON格式配置。配置安装的是数据，不是下方“引擎包”页面中的worker。
schema3可把自定义后缀交给随包提供的 Markdown、思维导图或draw.io能力；
它只选择固定能力，不安装或执行外部程序。下面三段是可安装的示例；本包
支持 `builtin.markdown`、`builtin.mindmap` 和 `builtin.drawio` 三种
schema3路由。历史上已接受的`.19`包只支持前两种。将三段分别保存为UTF-8
后安装，可把对应的 `.taskmd`、`.thoughts` 和 `.diagramnote` 文件交给
所选格式：

```json
{"schema":3,"id":"task-notes","name":"任务笔记","version":"1.0.0","apiVersion":1,"extensions":[".taskmd"],"nativeRoute":"builtin.markdown","lineComment":"#"}
```

```json
{"schema":3,"id":"thoughts","name":"想法导图","version":"1.0.0","apiVersion":1,"extensions":[".thoughts"],"nativeRoute":"builtin.mindmap"}
```

```json
{"schema":3,"id":"diagram-notes","name":"图表笔记","version":"1.0.0","apiVersion":1,"extensions":[".diagramnote"],"nativeRoute":"builtin.drawio"}
```

插件面板会显示“使用 Markdown”“使用 思维导图”或“使用 draw.io”，其“新建文档”使用
配置中第一个规范化后缀（补前导点、转小写、去重）和相应格式模板。
先注册的匹配配置优先；若该后缀已被其它配置匹配，新建会明确拒绝，
不会偷偷换用后面的后缀。禁用配置后，已打开文档按剩余配置重新匹配；
没有可用格式时仍可查看源码，可写文件仍能编辑保存，只读文件需另存为
可写副本。配置自身有独立的启用状态，不依赖任何内置格式的启用状态。

“另存为”按新路径重新匹配格式，不转换正文：例如把 Markdown 另存成
思维导图或draw.io后缀，不会生成有效的对应文档。`.diagramnote` 内容必须
是draw.io XML；改后缀不会把其它格式转换成draw.io。draw.io路由使用宿主
原生编辑器和选页SVG引擎，不提供思维导图式大纲或只读场景。源码模式不能
导出SVG，请先切换到可见的“阅读 / 编辑”或“分屏”并选中页面；页面消失或
身份变化会明确失败。既有draw.io子集保留未支持的XML并显示警告；未修改保存
保留原字节，支持范围的源码修改保留无关及未知XML元数据，但不等于所有
draw.io构造都能渲染。安装、禁用、新建、另存为前会处理当前原生编辑草稿；
写回失败或标签仍待添加时会拒绝操作并保留草稿，请按面板提示完成、放弃或
恢复输入。安装不覆盖已有文件或配置ID。schema1语法高亮和schema2字面大纲
配置仍可使用；schema3不接受schema2的 `outline` 规则，因为能力由所选格式
拥有，但并非每条路由都提供大纲。

“引擎包”页面只支持四个固定引擎：`levnote.markdown-export` 负责
Markdown HTML导出，`levnote.mindmap-svg` 负责思维导图SVG导出，
`levnote.mindmap-preview` 负责只读思维导图场景worker，
`levnote.drawio-svg` 负责当前选中页面的draw.io SVG导出。未知ID或额外
能力会被拒绝。“导入文件夹”要求选择一个完整的本地发布文件夹，只会复制
所选引擎的可执行程序、清单和必需的许可证/归属文件；导入完成后显示为
已导入但尚未启用。“检查列表”按需扫描已安装包。

启用时必须明确选择某个已安装版本和摘要；应用会在保存选择前校验该包
的精确内容。校验失败、所选文件缺失或损坏时明确拒绝，不会静默改用
随包引擎。“恢复随包”显式恢复对应引擎的随包选择；切换会保留当前
可写草稿和撤销历史，只读场景会在下一次绘制/显示警告时自动刷新，
刷新失败时保留原内容并显示失败提示。加载旧版schema1中保存的三个旧引擎
选择时会原样保留，并把新增draw.io视为随包引擎；只有显式保存选择时才写入
包含四个固定引擎的schema2状态。选择状态损坏会阻止所有四个引擎请求，此时
可用“重置全部引擎”恢复随包选择，已安装包仍保留。若取消后的进程清理
失败，本轮运行会阻止引擎切换，包括“重置全部引擎”；导入和
“检查列表”仍可独立使用。

旧包会保留；每个引擎最多12个本地包，四个引擎合计48个，当前没有删除
界面。导入、检查、启用等后台操作可取消；操作期间相关按钮会禁用。
若导入或选择已经完成提交，取消不会回滚该结果，当前状态以面板显示
为准；导入不会自动启用。取消后应用会等待清理完成，状态文本会更新。
启动时只读取有界的选择元数据，已安装包扫描仅在点击“检查列表”时
发生。引擎包状态位于
`%APPDATA%\LevNoteNative\engine-packages`，与程序目录分离；移动程序
目录不会自动移动这些状态。启动元数据读取仍有有界同步部分，最终
导出写文件也是同步执行且开始后不能取消；不应理解为所有I/O都已异步。

仅支持导入本仓库第一方固定引擎的完整发布目录，不支持任意可执行
插件。摘要和清单校验只证明复制后的本地文件与清单一致，不认证发布者，
也不为可执行程序提供沙箱。启用后应用会运行该本地可执行程序完成
对应预览或导出，请只导入可信发布目录。可编辑文档模型、布局、源码大纲
以及draw.io原生编辑仍由宿主处理；只读思维导图场景和draw.io SVG导出
各由单独worker完成。JSON格式配置仅路由到现有格式能力。

这是有明确范围的原生子集，尚无完整富文本/GFM、公式、Mermaid、图片编辑
或PDF，也不支持任意可执行插件安装。格式配置仅包含本地JSON数据，
包括语法高亮、字面大纲或上述固定格式选择。清单SHA256是文件一致性
检查，不是发布者认证或恶意程序沙箱。
