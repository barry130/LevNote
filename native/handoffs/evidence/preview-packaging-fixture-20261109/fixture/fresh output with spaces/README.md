# 轻笺原生版 · Windows amd64

在本目录双击 `levnote-native.exe`，或用 PowerShell 运行：

```powershell
.\levnote-native.exe
.\levnote-native.exe 'C:\Notes\说明.md'
```

Markdown HTML／思维导图 SVG 导出引擎和只读思维导图场景引擎版本：`fixture.1`。请整体保留本目录的 `engines/`、
`licenses/`、`attribution/` 和说明。配置/会话/本地JSON语法配置位于
`%APPDATA%\LevNoteNative`；移动程序目录不会移动用户数据。本目录不是
自包含用户配置的便携模式。

MyGo原生UI在宿主进程内绘制界面。Markdown HTML 与思维导图 SVG各使用一个
固定的一次性导出worker；可编辑思维导图的解析/布局和源码大纲解析仍在宿主。
只读思维导图预览由 `levnote.mindmap-preview` worker解析/布局，生成有界
场景DTO，宿主内原生UI直接绘制该DTO，不使用WebView，也不会改用宿主解析
或布局作为回退。worker仅在需要时启动，完成或取消后退出；源码模式导出
思维导图无需创建画布。请保留 `engines/markdown-export/`、
`engines/mindmap-svg/` 和 `engines/mindmap-preview/` 中各自的程序和清单。
导出显示进度和取消；预览缺失或损坏的引擎会显示失败，可切换源码模式查看
原文。来源变化或缺失/损坏引擎会明确拒绝，不会
静默回退到进程内导出。导出不覆盖已有文件，最终写入同步执行，开始后
不能取消。Markdown 源8MiB、思维导图源16MiB，结果各64MiB、默认30秒。
两种渲染器先在预算内计数，再按精确长度一次分配结果并填充，超限不返回
部分文件。这是输出缓冲限制，
不包含源文本/解析结构等内存，也不是进程峰值内存承诺或流式保证。只读
思维导图预览源码上限16MiB，场景DTO上限32MiB；布局、颜色和有界字面
标签由场景worker计算，宿主只负责绘制。

只读场景支持缩放、平移、节点选择与大纲导航；节点属性、标签和图片引用
请在源码中查看。需要修改时先“另存为”可写副本，随后可使用可编辑导图
的属性面板；切换源码本身不会解除只读。SVG导出仍可直接使用应用的
“导出”按钮，不必切换视图。下方标签编辑说明仅适用于可编辑思维导图。

思维导图 SVG 导出沿用节点图片的“图”占位；只读场景预览不加载或显示
图片，也不显示该占位徽标，图片引用仍完整保留在源码中。两者都不读取
图片文件或访问网络。未知字段和原始源码保持不变。
导出警告按整份源码范围报告，不代表精确节点位置；警告超过256项或元数据
字节上限会明确拒绝，不静默截断。draw.io SVG 仍使用宿主内既有路径。

支持的 Markdown 表格可双击单元格进入编辑，在单元格面板中插入或删除
数据行；表头只能在分隔行后插入。面板显示所选列和当前对齐，可按
“默认／左／中／右”修改该列，仅改变分隔行中这一列的冒号，保留原有
短横线数、空白、管道符、其它单元格和行尾。成功或相同对齐的无操作
都会结束单元格面板；无待写单元格修改时，相同对齐不改源码或撤销历史。
键盘操作先确认输入法组合，再按 F6 进入表格操作，Tab 切换按钮，
Enter/Space 执行。单元格有修改时先写回，列对齐或
行变更另记一次撤销。单元格写回失败时保留可恢复草稿；若单元格已写回
而列对齐或行操作被拒绝，已写回内容仍可单独撤销。单元格写回后对齐
无操作只保留单元格的撤销。超限或不支持的表格请使用源码编辑；尚无
列插入／删除、排序或新增表格语法。

可编辑思维导图选中节点后，在主要属性下方展开“标签”。可添加非空单行 UTF-8
标签（最多512字节），按序移除同名/空字符串旧标签，或清空为 `[]`；
对象标签和未知元数据随其它标签保留。面板最多处理64项、8KiB保留内容
预算，超限请用源码。实际修改会重新序列化JSON；未修改/拒绝/无操作
保存仍保留原字节。节点字段与标签修改分别撤销；字段已写回而标签被
拒绝时，字段仍可单独撤销。

尚未添加的标签不会随保存、导出、切换或关闭自动加入。请明确“添加
标签”、“放弃输入”或“恢复输入为新文档”；恢复会包含尚未写回的节点
字段和标签输入。待添加输入只保留在当前运行窗口，未承诺进入崩溃恢复
快照。组合输入先确认，再按F6进入操作；面板可滚动。画布/SVG仍显示
有长度上限的字面标签，未新增对象样式编辑、重命名、重排或全局检索。

这是有明确范围的原生子集，尚无完整富文本/GFM、公式、Mermaid、完整
图片管理、PNG/PDF或任意可执行插件安装。可安装插件仅为本地JSON语法/
字面大纲数据。清单SHA256是文件一致性检查，不是签名或恶意程序沙箱。
