## Development and product constraints

- All Go calls use `native/scripts/go.ps1 -GoArguments @(...)` from repository
  root. It selects checksum-verified Go1.27.3, local caches/vendor, startup safety
  patch and isolated configuration. Do not call system Go or raw tools/go.exe.
- Required checks must retain real command arguments/stdout/stderr/exit and
  before/after scope. `native/` is untracked: an empty git diff does not prove
  unchanged source. Use small actual file-hash inventories, not toolchain-wide
  rehash frameworks. Preserve failed attempts; never fabricate absent logs.
- MyGo provides drawing/font shaping/native input transport only. Do not use
  its prebuilt document editors. Format modules use host file APIs, no direct
  file access. Keep dependencies pointed into neutral editor contracts.
- App runtime is pure local: no account, sync, telemetry or network requests.
  Format JSON is nonexecuting. Fixed catalog executable engines are separately
  imported and explicitly activated; no arbitrary executable-path override.
  Checksums verify local integrity, not publisher authentication or sandboxing.
- Preserve unknown metadata, original untouched bytes, readonly/encoding/BOM,
  undo and uncommitted drafts. No silent overwrite/transcode/fallback/loss.
  Plaintext/byte inspection stays reachable for unsupported content. Limits,
  missing capabilities and failures must be visible.
- Import is not activation; package selection transitions join captured old
  work before persistence. Cleanup error can follow a committed selection:
  display actual state, don't infer rollback. Import/list remain usable under
  runtime cleanup poison; transitions/execution are blocked. Readonly scene
  refresh preserves selection until the replacement lacks that node. Never
  flush/release writable views just to change engine selection.
- Do not edit another owner's files. Keep scope finite; avoid duplicate gates,
  rerunning accepted unchanged suites or unnecessary product layers. Needed
  corrections are delegated; root doesn't implement or run acceptance tests.
