Each package owns its case-sensitive, ordinal dictionary of full `Test` strings. Every slash-free identity remains an independent record, including `Example` and `ExampleWidget`; there is no new `Test` prefix rule or Go function-name validator. For a slash-bearing run, the exact component before the first ASCII `/` must match an already run, nonterminal slash-free identity in that same package. Each accepted slash run adds one unfinished identity to that top-level record; its unique valid pass or reasoned skip releases one. Pausing, continuing and output leave this count unchanged. A top-level terminal is refused while any such slash identity is unfinished.

JSONL cannot reconstruct true middle-parentage. Go permits `/` inside one `t.Run` label. Thus `TestParent/Group` and `TestParent/Group/Label` can be two direct children of `TestParent`, or the latter can be a real child created by `Group`. The reducer does not infer edges from middle string prefixes, require intermediate events, or check intermediate parent/child completion order. Both sibling terminal orders are accepted by design. The nested control demonstrates one possible intended Go construction; its JSONL alone does not prove that construction.
