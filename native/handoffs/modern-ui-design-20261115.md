# 轻笺现代工作台设计

用户反馈上一版仍显陈旧，要求更现代的UI。本轮实现实际MyGo原生界面并交付新体验包。

## 视觉决策

借鉴Fluent/Linear的轻量层次，针对本地阅读写作工具采用安静的石墨蓝灰工作台。突出文件和正文；导航与状态退后，避免满屏高亮蓝色条及密集分割线。
深色基础：chrome #171b24、sidebar #1b202a、canvas #202530、hover #2b3343、text #e1e7f0、accent #4263d8；muted保证4.5:1，选中面用低饱和蓝灰。浅色为#eff2f6导航、#ffffff正文、#253149文字和#4263d8强调。
字体沿用本地Microsoft YaHei UI以保证中文，但从12/13提高到13/14；品牌16、欢迎标题28–32。正文尊重用户原字号偏好。按钮圆角6、标签8、欢迎主入口10，分隔线只用于真正的层级。

## 布局合同

顶部56px：轻笺图形标志+新建/打开/最近关闭/文件夹/保存，再接真实文档搜索胶囊（Ctrl+P），在760px仍可操作；搜索调用openDocumentPicker并KeepFocus，禁止制造假搜索。
左活动栏56px，内部40×40图标按钮居中并留白，选中使用圆角淡底与清晰图标色。侧栏保留原用户宽度/窄窗至少480px文档，根目录标题14，树行32，文本13，图标统一。
标签导航44px，圆角平面选中标签、自然留白，不画密集格子与顶部长蓝线；选中/未选中/脏标记可辨，close/reveal/t.ID保留。文档工具栏42px，阅读/源码/分屏组成紧凑分段控件，主编辑表面保持安静。
状态栏29px，改成同背景灰阶；消息、错误、只读、编码、行列、问题入口全部保留且交互对比度至少4.5。
欢迎页以真实的“新建 Markdown”“打开文件”作为主次操作，宽窗舒展布局、窄窗滚动；无广告、无假的最近文件/统计、无装饰性功能。

## 行为与验收

保留所有路径/稳定key/实际可访问名字/disabled/KeepFocus/组合输入守卫，默认深色和已存light优先不变。编辑/编码/字节/undo/草稿内核不改。只对过时的精确几何测试适配，核心操作及边界不断言放宽。
先读现有实现再改；两实现分工互不写对方文件，不跑并行Go命令。lead统一聚焦测试、六场景截图与最终app相关回归、vet、构建。原 .1-preview 包及历史证据保留，新包 .2-preview。

## 自检

现代感来自空间、字号、交互与层级，不能只再换一组颜色。避免所有区域套圆角卡片；唯一显著元素是顶部可用的文档搜索，其余服务阅读写作。保持本地原生，而非重启legacy网页外壳。
