# LevNote 原生工作台视觉改造

用户要求参照 VS Code 美化当前原生界面。目标是可实际使用的工作台布局，继续使用 MyGo Surface 与现有自研编辑器。

## 视觉方案
- 深色：编辑区 #1f1f1f、工作台与侧栏 #181818、悬浮 #2a2d2e、边界 #2b2b2b、正文 #cccccc、强调 #0078d4；状态栏 #007acc 配白色。亮色对应白色编辑区、#f3f3f3 侧栏、细灰分隔，保留用户已有主题选择。
- 字体：UI Microsoft YaHei UI 12–13px，正文编辑继续使用现有字体与用户字号；欢迎页标题约28px、说明13px、快捷键11–12px。
- 布局：顶部紧凑命令区，48px 图标活动栏，约220px资源管理器，主区平直标签页、细面包屑/模式栏与大块编辑区，24–26px状态栏。760×480最小窗口保留主操作与可见状态。
- 控件使用2–3px小圆角、细分隔和明确悬浮/焦点反馈；活动项蓝色竖线、标签激活顶线；避免圆角按钮堆叠与装饰性卡片。
- 活动栏只接入现有文件树、大纲、查找、插件和设置；不增加虚假的终端、Git或账号入口。欢迎页提供现有打开文件、新建Markdown与快捷键入口。

## 兼容与验收
- 保留现有命令语义、快捷键、控件稳定key、草稿/组合输入所有权、只读与字节保真。
- 既有theme偏好优先；未选择主题的新配置采用深色。
- 外观截图由真实a.View/MyGo Tester输出，覆盖亮/暗、文档/欢迎页与760×480；不当作物理桌面验收。
- 新代码限定app视觉与ui层；既有未提交围栏/恢复修复完整保留，vendor/工具链/.29包和历史证据保持原样。
- 独立审阅、相关回归与最终产品门禁在新证据目录保存真实命令、输出和退出码；不创建commit或push。
