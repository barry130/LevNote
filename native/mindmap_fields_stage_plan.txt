Required design decisions before implementation:
1. Exact optional-field semantics. Existing absent note vs explicit empty note
   stay unchanged on no-op. Clearing a nonempty note may store explicit empty
   string; an empty hyperlink must remove that optional key because the current
   format requires a nonempty string when present. Never trim/normalize authored
   strings silently. Mutators mark dirty only on semantic change and preserve
   unknown/raw metadata; rejected input cannot partially mutate the document.
2. Field identity includes buffer+node+field+original value AND presence, not
   only current selected node. Source edits in a different field may merge;
   same-field edits/deletion/Buffer replacement conflict, retaining draft. No
   close/switch/Release silently drops a failed draft. RecoverDraft must identify
   the field and original node and keep exact text in an unsaved separate copy.
3. Choose a field first, then edit with the existing self-authored editor. A
   field switch Flushes before replacing the one active draft and refuses on
   conflict. Native Compose then save/mode/tab/field switch must commit once or
   preserve the conflict. Avoid three always-live editors per selected node.
4. Notes remain literal plain text. No Markdown parser/remote content on notes.
   Existing editor ShapeLimit and bounded inspector viewport must apply. Long
   existing fields stay readable/editable through the normal segmented path,
   not silently shortened into the stored value. Pick a justified finite bound
   for copied hyperlink button metadata; source stays complete and over-budget
   targets are visibly unavailable, never shortened to another destination.
5. Opening a link must Flush the active draft, validate current source node/field
   identity, and call the existing Host.OpenReference exactly once. Do not route
   through OS URL APIs or a second path classifier. Literal relative/file URL
   policy and readonly navigation stay consistent with Markdown. If Flush edited
   the hyperlink itself, choose/document safe exact activation semantics rather
   than navigating to a stale captured target. Pending conflict blocks opening.
6. No-op field selection/read/open/export/save should not dirty/reformat source.
   A real field edit is a single appropriate undo transaction; untouched unknown
   fields survive. Document the existing JSON reserialization boundary after
   edits. UI copy should clearly label plain note/local link and unsupported URL
   refusal. No new dialogs or decorations without a workflow purpose.
